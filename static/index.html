待决定
  • 设备重命名 / 隐藏空设备：区分多台 Mac、旧 iPhone；当前已支持筛选与隐藏空设备。
  • 系统活动排除规则：让锁屏、主屏幕是否计时由你决定，并提供包含 / 排除对比。
  • 区间对比：本周对上周，显示每个分类多用了多少时间。
  • CSV 导出与备份恢复：导出会话，备份重命名和分类设置。
  • 细分规则 / 多级分类：按应用标识自动分类；浏览器内网页需要另采集数据。
  • 时间线异常检查：提示超长会话、同设备重叠、疑似重复设备，人工确认后再处理。
  • 每日简报 / 只读 MCP：查询用时与作息；使用时间数据无法还原阅读内容。
  • 手机远程查看：现可通过局域网访问；公网 HTTPS 与服务器部署待决定。
